# Sorting Algorithm Visualizer

This project is a Sorting Algorithm Visualizer that allows users to see various sorting algorithms in action. It provides an interactive interface to input custom numbers or generate random ones, sort them using different algorithms, and compare their performance based on time taken and swap count.

## Features

- **Visual Representation**: Animates sorting step-by-step.
- **Multiple Sorting Algorithms**: Supports Bubble Sort, Selection Sort, Quick Sort, Insertion Sort, Heap Sort, and Merge Sort.
- **User Input**: Users can input their own array values.
- **Random Number Generation**: Generate random arrays for sorting.
- **Comparison Mode**: Compare all sorting algorithms based on time and swaps.
- **Charts**: Displays performance metrics using bar charts.
